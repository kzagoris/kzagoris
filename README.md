## Selected projects

### [WinMTR Remaster](https://github.com/kzagoris/winmtr-remaster)

The classic WinMTR, rebuilt on Avalonia and .NET 10. Traceroute and ping in one window, on Windows, macOS and Linux. No runtime to install.

[Download](https://github.com/kzagoris/winmtr-remaster/releases) · [How I ported it](https://www.wittyprogramming.dev/articles/porting-winmtr-to-avalonia/)

### [RSMF — Remote Student Monitor Framework](https://github.com/kzagoris/rsmf-app)

I designed and built this remote-examination platform end to end using **React, TypeScript, MUI, Firebase, and WebRTC**. It includes course, student and exam management, role-based workflows, peer-to-peer video monitoring, face detection, and event-triggered recordings for proctor review.

[Public source](https://github.com/kzagoris/rsmf-app) · [Project website](https://www.rsmf-project.eu/) · [Demo video](https://youtu.be/3AfzDNmYFv4)

### [Proxenos](https://github.com/kzagoris/proxenos)

A **Kotlin/JVM** developer tool that connects ChatGPT to selected local workspaces through the OpenAI Secure MCP Tunnel. A terminal dashboard manages workspace access and activity; a separate runtime supports file operations, Git inspection, and command execution. Built with Ktor, the MCP Kotlin SDK, and Mosaic.

[Source and setup](https://github.com/kzagoris/proxenos)
